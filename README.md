# Oasis Infobyte Data Science Internship (OIBSIP)

This repository contains the complete set of end-to-end Data Science and Machine Learning projects completed during the **Oasis Infobyte Internship Program**. Each project follows a structured workflow: data cleaning, exploratory data analysis (EDA), model training, benchmarking, and documentation.

---

## 📁 Projects Overview

| Task | Project Name | Domain | Key Technologies | Folder Link |
| :--- | :--- | :--- | :--- | :--- |
| **Task 1** | Iris Flower Classification | Multiclass Classification | Scikit-Learn, Decision Trees | [View Task 1](./DataScience-Task1-IrisClassification) |
| **Task 2** | Unemployment Analysis with Python | Exploratory & Time-Series EDA | Pandas, Seaborn, Matplotlib | [View Task 2](./DataScience-Task2-UnemploymentAnalysis) |
| **Task 3** | Car Price Prediction | Regression & Feature Engineering | Scikit-Learn, Random Forest | [View Task 3](./DataScience-Task3-CarPricePrediction) |
| **Task 4** | Email & SMS Spam Detection | Natural Language Processing (NLP) | TF-IDF, Naive Bayes | [View Task 4](./DataScience-Task4-EmailSpamDetection) |
| **Task 5** | Sales Prediction Using Python | Multiple Linear & Ridge Regression | Scikit-Learn, Regression | [View Task 5](./DataScience-Task5-SalesPrediction) |
